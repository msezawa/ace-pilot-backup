Privacy policy

Last updated: 2026-10-13

What this app accesses

ACE Pilot backup requests only the Google Drive scope drive.file. It can see and change only the files that it creates itself in the owner's Google Drive. It cannot see any other file.

How the data is used

The app stores backup copies that are encrypted on the owner's computer before they are uploaded. The contents cannot be read without the owner's password, which is never uploaded.

Sharing

No data is shared with, sold to, or used by any third party. There is no analytics, advertising, or tracking.

Who uses it

Only the owner of this app uses it. It is not offered to the public.

Removing access

Access can be removed at any time from the Google Account's third-party access settings.

日本語の要約

このアプリが触れるのは、自分で作ったバックアップのファイルだけです（drive.file）。中身はアップロード前に暗号化され、パスワードはアップロードしません。データを第三者に渡すことはなく、利用者は所有者本人だけです。
