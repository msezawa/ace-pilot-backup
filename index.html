ACE Pilot backup

ACE Pilot backup is a personal backup tool used only by its owner. It uses rclone to store encrypted backup copies in the owner's own Google Drive. It is not offered to, and cannot be used by, anyone else.

ACE Pilot backup は、所有者本人だけが使う個人用のバックアップ道具です。rclone を使い、暗号化したバックアップを所有者自身の Google ドライブに保存します。他の人には提供していません。
