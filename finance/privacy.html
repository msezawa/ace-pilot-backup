Privacy policy

Last updated: 2026-10-18

What this app accesses

finance-desk requests only the Gmail scope gmail.compose. It uses it to create a draft email and to read back that same draft to check it. It never sends, deletes, labels, or moves any email. The owner sends each draft personally.

How the data is used

Drafts are made on the owner's computer from invoices the owner has approved. There is no server operated by the developer; nothing is uploaded anywhere except to the owner's own Gmail as a draft.

Limited Use

finance-desk's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is not used for advertising, is not sold, and is not used to train generalized AI or machine-learning models.

Sharing

No data is shared with, sold to, or used by any third party. There is no analytics, advertising, or tracking.

Who uses it

Only the owner of this app uses it. It is not offered to the public.

Removing access

Access can be removed at any time from the Google Account's third-party access settings.
