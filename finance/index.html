finance-desk

finance-desk is a personal tool used only by its owner. With the owner's permission, it creates draft emails in the owner's own Gmail, with the owner's invoice PDF attached, on the owner's computer. The owner checks each draft and sends it personally. The tool never sends, deletes, labels, or changes email.

It is not offered to the public.

日本語の要約

本人だけが使う個人の道具です。本人の許可を得て、本人のパソコンから、本人の Gmail に請求書の PDF を添付した下書きを作ります。下書きは本人が確かめて、本人が送ります。メールの送信・削除・ラベルの変更はしません。一般には提供していません。
